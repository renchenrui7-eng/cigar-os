一、这是什么

Cigar OS 是一个全球雪茄参数化知识底座（STAR-4L 架构），本工作台是其可视化前端。全部数据——663 个实体、309 款雪茄型号、6962 条知识三元组——内置于应用中，离线可用，无需联网、无需注册。

数据来源：Cigar Aficionado 2025 Top 25 盲评榜单 + 全网专业配对指南，每款型号含完整配方（茄衣/茄套/茄芯）、风味三段、CA 评分、价格档与品吸时长。

三、安装到桌面 / 手机（PWA）

本应用是 PWA（渐进式 Web 应用），可像原生 App 一样安装，安装后离线可用：

  • 桌面 Chrome / Edge：地址栏右侧安装图标，或点击顶部「⬇ 安装」按钮
  • iPhone（Safari）：分享 → 「添加到主屏幕」
  • Android（Chrome）：菜单 → 「安装应用」/「添加到主屏幕」
  • macOS Safari：分享 → 「添加到 Dock」
注意：本地 file:// 打开（未部署到服务器时）不支持 PWA 安装与 Service Worker，功能不受影响，仅离线缓存与安装不可用。部署版（GitHub Pages / CloudStudio）完整支持。

四、MCP Server（AI 助手接入）

同一知识库还提供 MCP Server，可让 Claude / Cursor / WorkBuddy 等 AI 客户端直接查询雪茄知识：

  1. 安装依赖：pip install fastmcp
  2. 运行测试：python cigar_mcp_server.py（stdio 模式）
  3. 客户端配置（以通用 MCP 配置为例）： 
    {
  "mcpServers": {
    "cigar-os": {
      "command": "python",
      "args": ["C:/path/to/cigar_mcp_server.py"]
    }
  }
}
  4. 可用工具：search_cigar（型号检索）/ recommend_cigar（品鉴推荐）/ pair_beverage（配餐）/ humidor_check（养护诊断）/ explore_graph（图谱遍历）/ kb_stats（底座统计）

五、数据更新与重建

知识库更新后，一条命令重建站点：

  1. 编辑 Knowledge_Base/L2_Entity_Dictionary_Part*.json（新增/修改实体）
  2. 运行 python build_cigar_site.py —— 重新生成 cigar-site/data.js
  3. 把 cigar-site/ 整个目录部署到任意静态托管（GitHub Pages / CloudStudio / Vercel）

七、常见问题

  • Q：评分体系是什么？ CA（Cigar Aficionado）100 分制盲评，95+ 即为年度顶级。推荐引擎评分是内部匹配分，与 CA 无关。
  • Q：为什么有些型号没有 CA 评分？ CA 只对进入盲评的型号打分，未上榜型号显示 –。
  • Q：投资评级可信吗？ 综合评分/稀缺/陈化的加权参考值，不构成投资建议。
  • Q：支持什么语言搜索？ 中英文均可——"黑胡椒"、"black pepper"、"高希霸"、"Cohiba" 都能命中。

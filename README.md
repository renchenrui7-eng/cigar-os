# Cigar OS · 全球雪茄参数化知识底座

> STAR-4L 架构（Semantic Tree + Atomic Records + Relational Links）驱动的雪茄知识库与 PWA 工作台。

**在线体验**：https://renchenrui7-eng.github.io/cigar-os/

## 数据规模（v2.4）

| 维度 | 数量 |
|---|---|
| 实体 | 663（60 地理 + 17 品种 + 57 品牌 + 90 风味 + 5 工艺 + 4 工具 + 15 配饮 + 2 人物 + 309 雪茄型号） |
| 三元组 | 6,962 条（32 种谓词，引用零悬空） |
| CA 95+ 评分型号 | 64 款（Cigar Aficionado 2025 Top 25 真实数据） |

## 工作台功能（PWA，可安装到桌面/手机）

- **总览** — 数据全景与统计分布
- **型号库** — 309 款雪茄全字段检索
- **智能品鉴** — 强度 + 风味推荐引擎
- **配餐顾问** — 型号 ↔ 配饮双向匹配
- **养护顾问** — 温湿度 5 档诊断（甲虫/霉变预警）
- **收藏投资** — CA 95+ 名单与投资评级
- **图谱探索** — 6962 条关系双向遍历
- **知识百科** — 产区/工艺/品牌/历史
- **对比** — 1-3 款 17 维度横评
- **说明书** — 内置完整使用文档

## 技术栈

- 纯静态单页应用（零依赖、离线可用）
- PWA：manifest.json + Service Worker（sw.js）
- 数据源：L2 实体字典 + L3 三元组库 → `data.js`（构建脚本自动注入）
- 配套 MCP Server：见仓库说明（`cigar_mcp_server.py`，9 个工具供 AI 客户端调用）
